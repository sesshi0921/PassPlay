# PassPlay マニュアル

スマホ1台を回しながら遊ぶ「パスプレイ式」多人数ゲーム集。

## ゲームを始める

- [プレイページ（GitHub Pages）](../index.html)

## 収録ゲーム

| ゲーム | 推奨人数 | 説明 |
|---|---|---|
| [ワードウルフ](./word-wolf.md) | 3〜16人 | 似た単語に紛れ込んだ人狼を見つける議論ゲーム |

## 共通の遊び方

1. プレイページを開く
2. 全員の名前を「プレーヤー」欄に登録
3. 遊びたいゲームのアイコンをタップ
4. 画面の指示にしたがって端末を順番に回す
