# ワードウルフ

似た単語に紛れ込んだ1人の「人狼」を、議論と投票で見つけ出す多数決ゲーム。

## 基本情報

| 項目 | 内容 |
|---|---|
| 推奨人数 | 3〜16人 |
| プレイ時間 | 5〜15分 |
| 必要なもの | スマホ1台 |
| 配色テーマ | 暗赤×黒（盗み見しにくい） |

## 役割

- **多数派（村人）**: 「お題の単語」が配られる人。多数を占める
- **人狼**: 1人だけ違う単語が配られる人。バレないように議論する

## 流れ

### 1. プレーヤー登録
トップページで全員の名前を入力する。

### 2. 単語確認（reveal）
端末を順番に回す。自分の番が来たら：
1. 「タップして単語を見る」ボタンを押す
2. 自分の単語を覚える
3. 「確認した・次へ」を押す
4. 次の人に端末を渡す

### 3. 議論時間の選択（timer-setup）
全員確認後、議論時間を選ぶ：
- 1分 / 3分 / 5分 のプリセット
- 自由入力（1〜30分）

### 4. 議論（discuss）
全員でお題について話す。例:
- 「それって辛いやつ？」
- 「俺はよく朝食べるかな」

人狼は周りの発言から「自分の単語と違うかも」と気付き、ぼかして発言する必要がある。

時間が来るか、「投票へ進む」ボタンで投票フェーズへ。

### 5. 投票（vote）
端末を回しながら、1人ずつ「怪しい」と思う人を選ぶ。
- 自分自身には投票できない
- 全員投票が終わると結果発表へ

### 6. 結果発表（result）
- 最多得票者の発表
- 人狼の正体
- 多数派の単語 / 人狼の単語
- 各プレーヤーの得票数

**勝敗判定:**
- 最多得票者が人狼だけ → **村人の勝利**
- 同票で人狼が含まれる → **村人の勝利**
- それ以外 → **人狼の勝利**

## コツ

- **村人**: 抽象的すぎる発言は人狼の擬態を許す。具体的な情報（色、食感、買う場所）を出す
- **人狼**: 序盤は相手の発言を引用してオウム返し気味に。終盤は自分の単語にも触れて「合わせ」を狙う

## トラブル時

- 単語を見間違えた → 「もう一度」で同じプレーヤーで再戦可能（新しい単語ペアが選ばれる）
- 端末を見られそうになる → reveal は1タップで非表示にして次の人に渡す
